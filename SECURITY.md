# Security policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Please don't open a public issue.

Report it privately through GitHub: **Security → Report a vulnerability** on this repository ([direct link](https://github.com/FreddieMcHeart/moneyflow/security/advisories/new)).

Include what you found, how to reproduce it, and what it affects. You'll get a reply within 7 days.
